
# Network Security Interview Questions 21-30 (With Detailed Answers)

## 21. What are common ports for HTTP/HTTPS, DNS, SSH, RDP, and SNMP?
Common network services rely on well-known ports to establish standardized communication. HTTP uses TCP port 80, while HTTPS uses TCP port 443 as an encrypted alternative relying on TLS. DNS typically runs on UDP port 53 for queries and TCP port 53 for zone transfers. SSH, used for secure remote access and tunneling, operates on TCP port 22. RDP, Microsoft's remote desktop protocol, uses TCP port 3389. SNMP for network monitoring uses UDP ports 161 for queries and 162 for traps. Understanding these ports is essential for configuring firewalls, intrusion detection systems, and network segmentation.

## 22. Explain 802.1X authentication.
802.1X is a port-based network access control protocol that authenticates devices before granting them network access. It relies on three components: the supplicant (endpoint), the authenticator (switch or wireless AP), and the authentication server (typically RADIUS). The process begins when a device connects; the authenticator blocks all traffic except EAP messages until authentication completes. Credentials or certificates are verified using EAP methods such as EAP-TLS or PEAP. Once authenticated, the device is assigned a VLAN or access policy. 802.1X enhances security by preventing unauthorized devices from accessing LAN or WLAN resources.

## 23. What is DHCP snooping and why is it important?
DHCP snooping is a Layer 2 security technique that prevents rogue DHCP servers from assigning malicious IP configurations to clients. Switches classify ports as trusted or untrusted; only trusted ports can send DHCP offers or ACKs. The switch builds a DHCP snooping binding table that maps MAC, IP, lease time, and VLAN information. This table is used by other security features like dynamic ARP inspection and IP source guard. DHCP snooping mitigates attacks such as DHCP starvation, spoofing, and man-in-the-middle attempts that rely on falsifying IP assignment. It's crucial in enterprise networks to maintain IP integrity and device identity.

## 24. What is MACsec and where is it used?
MACsec (Media Access Control Security) is a Layer 2 security protocol that provides encryption and integrity protection for Ethernet frames. It secures traffic between switches, access points, servers, and endpoints using AES-GCM encryption. MACsec prevents eavesdropping, replay attacks, and tampering on wired LAN links. Organizations use MACsec in data centers, campus networks, and sensitive environments where physical access cannot be fully controlled. It integrates with 802.1X and MKA (MACsec Key Agreement) to automate key exchanges and enforce authentication before enabling encryption.

## 25. Explain BGP route filtering and its security importance.
BGP route filtering ensures routers exchange only legitimate prefixes, preventing accidental or malicious route propagation. Administrators implement prefix lists, route maps, AS-path filters, and max-prefix limits to validate received routes. This mitigates risks like route leaks, hijacks, and misconfigurations that could disrupt global or internal routing. ISPs and enterprises deploy RPKI (Resource Public Key Infrastructure) to cryptographically validate route origins. Effective filtering protects against distributed routing failures, BGP hijacks used for traffic interception, and accidental outages caused by improper advertisements.

## 26. What is a DDoS attack and how do you prevent or mitigate it?
A DDoS attack floods a target with massive traffic or resource-exhaustion requests from distributed sources, overwhelming availability. DDoS attacks include volumetric floods, protocol exhaustion, and application‑layer attacks. Mitigation involves rate limiting, ACLs, upstream traffic scrubbing, load balancing, and using content delivery networks to absorb traffic. Cloud DDoS protection services use behavioral analytics and automated filtering. Network teams also deploy blackholing or sinkholing during severe attacks. Defense requires both proactive design (redundancy, scalable bandwidth) and reactive mechanisms.

## 27. How does malware typically spread across a network?
Malware spreads through vectors such as email attachments, drive‑by downloads, compromised websites, USB devices, and exploitation of unpatched vulnerabilities. Lateral movement occurs when malware uses stolen credentials, SMB exploits, RDP brute force, or remote code execution to move deeper inside a network. Worms self‑propagate by scanning for vulnerable hosts, while trojans disguise themselves as legitimate files. Malware command‑and‑control channels help attackers maintain persistence. Network segmentation, patching, endpoint detection, IDS/IPS, and user training are key defenses.

## 28. What is ARP spoofing and how do you prevent it?
ARP spoofing occurs when an attacker sends forged ARP replies to associate their MAC address with another device’s IP address, intercepting or manipulating traffic. This enables man‑in‑the‑middle attacks, session hijacking, and data theft. Prevention includes Dynamic ARP Inspection (DAI), static ARP entries in sensitive systems, VLAN segmentation, and DHCP snooping integration. IDS systems can detect unusual ARP patterns. Encryption protocols like HTTPS help protect data even if interception occurs.

## 29. What is a man‑in‑the‑middle (MITM) attack?
A MITM attack occurs when an attacker secretly intercepts, relays, or alters communication between two parties who believe they are directly connected. It can happen through ARP spoofing, rogue Wi‑Fi access points, DNS poisoning, or SSL stripping. MITM attackers capture credentials, inject malicious payloads, or modify transactions. Prevention includes TLS encryption, certificate pinning, secure Wi‑Fi authentication (WPA3/802.1X), DNSSEC, VPNs, and ARP defense mechanisms. Continuous monitoring and anomaly detection further help identify MITM attempts.

## 30. What is lateral movement in cyberattacks and how do you prevent it?
Lateral movement refers to how attackers move within a compromised network to access higher‑value systems. Techniques include credential dumping, pass‑the‑hash, RDP pivoting, SMB exploitation, and remote execution tools like PsExec or WMI. Defenses include strong segmentation, least‑privilege access, MFA, disabling unused protocols, and monitoring east‑west traffic using IDS/IPS. EDR tools detect abnormal processes and remote activity. By restricting internal mobility, organizations reduce the blast radius of breaches.
